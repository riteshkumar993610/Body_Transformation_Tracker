# 🏋️ Body Transformation Tracker

> A modern and responsive React-based fitness and nutrition tracking application that helps users monitor their food intake, nutrition, fitness goals, and transformation journey in one place.

---

## 📌 About The Project

**Body Transformation Tracker** is a web application designed to make daily fitness and nutrition tracking simple, organized, and user-friendly.

The application allows users to explore food items, filter foods according to their meals and fitness goals, calculate nutrition based on the quantity consumed, and maintain their personal profile and fitness information.

The main objective of this project is to provide a **simple digital platform for tracking nutrition and supporting consistent fitness habits.**

---

## ✨ Key Features

### 🍎 Food & Nutrition Management
- Browse a collection of food items with nutritional information.
- View calories, protein, carbohydrates, fats, and fiber.
- View detailed information about individual foods.
- Add food according to the quantity consumed.
- Automatically calculate nutrition based on selected quantity.

### 🍽️ Meal-Based Tracking
Foods can be organized according to different meal categories:

- 🌅 Breakfast
- ☀️ Lunch
- 🌙 Dinner
- 🍎 Snack

### 🎯 Goal-Based Food Filtering

Users can explore foods according to different fitness and nutrition goals, such as:

- 💪 Muscle Gain
- 🦴 Strong Bones & Teeth
- ✨ Healthy Hair & Skin

### 👤 Profile Management

Users can maintain their personal fitness information including:

- Name
- Age
- Gender
- Height
- Weight
- Target Weight
- Fitness Goal
- BMI

### 📊 Nutrition Calculation

The application dynamically calculates nutritional values based on the quantity of food selected.

For example:

> If a user selects a specific quantity of a food item, the application automatically calculates the corresponding calories, protein, carbohydrates, fats, and fiber.

### 📱 Responsive User Interface

The application is designed to work across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

The interface includes a mobile-friendly navigation system and responsive food cards.
